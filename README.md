# Personal Knowledge Base

个人前端知识库（Obsidian 仓库），围绕前端核心知识体系持续积累，内容以「机制 + 实测 + 面试速记」的方式组织：概念不止于定义，尽量附可运行验证、本机实测数据和踩坑记录。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| [JavaScript 核心/](JavaScript%20核心/) | 语言核心：闭包、原型、事件循环、内存管理等 |
| [浏览器原理/](浏览器原理/) | 渲染管线、Update Rendering、进程模型等 |
| [网络/](网络/) | HTTP 演进、HTTPS、缓存等 |
| [音视频/](音视频/) | MSE/WebCodecs/WASM 软解管线、YUV 与 WebGL 渲染、编解码原理、音画同步等，多数结论有本机实测 |
| [前端工程化/](前端工程化/) | 构建、工程实践与实验 |
| [node/](node/) | Node.js 相关 |
| [安全/](安全/) | Web 安全主题 |
| [seo/](seo/) | 性能优化与 SEO |
| [手写题/](手写题/) | 常见手写实现 |
| [面试速记/](面试速记/) | 高频考点速记索引 |

## 约定

- 笔记使用 Obsidian 双链 `[[]]` 互相引用，推荐用 Obsidian 打开阅读；
- 置顶引用块是每篇的**结论先行**，正文再展开原理/实测/取舍；
- 涉及兼容性、性能的结论尽量附实测环境（浏览器版本/硬件）与验证脚本；
- 面试相关的私人内容（复习计划、模拟面试话术等）不入库，已在 `.gitignore` 中排除。
