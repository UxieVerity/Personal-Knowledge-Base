# 02 · 从词向量到 Transformer：一次被「逼」出来的技术演进

> **结论先行**：这一期是全系列的**问题链**。每一次技术换代都不是因为喜欢新名词，而是旧方案撞上了一堵墙：n-gram 撞墙在**组合爆炸 + 不懂语义**；词向量解决了「语义」；前馈神经网络解决了「复杂规律」，但撞墙在**固定窗口**；RNN 用隐藏状态解决了「长度」，但撞墙在**长期依赖 + 顺序计算**；LSTM 用细胞状态 + 三门解决了「记不住」，但撞墙在**只能串行 + 远距离仍要绕路**。最后那三个问题——「能不能让每个 token 直接去找最相关的 token」「能不能同时处理所有 token」「没有 RNN 之后顺序信息从哪来」——正是 Transformer 的出题动机。记住这条链，比记住每个名词的定义有用得多。

## 〇、总览：一条「越修越坏、越坏越修」的路线

| 阶段 | 解决的问题 | 撞上的墙 |
| ---- | ---- | ---- |
| n-gram | 用统计预测下一个词 | 组合爆炸、不懂语义、无法泛化到没见过的组合 |
| 词向量 | 把词语义变成向量，可算相似度 | 单独用不能预测（n-gram 依然是数数） |
| 前馈神经网络 | 吃词向量，学复杂规律 | **固定窗口**，超窗口的信息当没出现过 |
| RNN | 隐藏状态压缩前文，可读任意长 | **长期依赖**（旧信息被覆盖、梯度传不回去） |
| LSTM | 细胞状态 + 三门，选择性记忆 | **必须串行**、远距离仍要逐步传递 |
| Transformer | 每 token 直接找相关的 token，全并行 | （下一期） |

## 一、起点：猜词游戏

「轩辕养了一只 ____」 → A 熊猫 B 汽车 C 鹦鹉 D 苹果。人一眼选 C：汽车、苹果不通，熊猫（虽然人在四川）养不了。人靠的是**语义常识**。

计算机眼前只有一串文字符号：它不知道什么是鹦鹉，也不知道「养了一只」后面通常接动物。怎么办？

## 二、n-gram：用统计数数

让程序读大量文章，统计词语组合出现次数：

| 组合 | 出现次数 |
| ---- | ---- |
| 养了一只猫 | 10000 |
| 养了一只狗 | 8000 |
| 养了一只鹦鹉 | 2000 |
| 养了一只苹果 / 汽车 / 熊猫 | 0 |

看到「养了一只」就去查历史统计，概率最高的就是答案 → 选 C。

**术语**：

| 名称 | 看前几个词 | 英文 |
| ---- | ---- | ---- |
| 二元模型 | 1 个 | bigram |
| 三元模型 | 2 个 | trigram |
| n-gram | n−1 个（泛指） | n-gram |

> 📌 **token 是什么**：模型读取和预测文本的基本单位。有时是一个完整的词、一个汉字、一个标点，也可能只是英文单词的一部分。常见词保留为完整 token，不常见词被拆成更小的片段（怎么拆不是本期重点）。

### 墙一：组合爆炸

词表 10 万个词，只考虑两两组合就有 $$10^5 \times 10^5 = 10^{10}$$ 种；考虑三词、四词会迅速膨胀。现实中句子千变万化，再大的语料也覆盖不完所有合理组合。

### 墙二：每个词是孤立的符号

把选项 C 换成「虎皮鹦鹉」：

- 人：照样一眼选出——虎皮鹦鹉也是一种鹦鹉，也能被饲养；
- n-gram：训练语料里出现过「养了一只鹦鹉」，但**从没出现过「养了一只虎皮鹦鹉」**，这是全新组合，它不知道两者有什么关系 → 选不出来。

根因：**在 n-gram 眼里，猫、狗、鹦鹉各是一个独立符号**，它不知道猫狗鹦鹉都属动物，也不知道鹦鹉和虎皮鹦鹉含义接近。所以**学到的规律无法迁移**到没见过的新句子。

## 三、词向量：把「含义」交给计算机

### 3.1 先人工设计两个特征

每个词用 2 个数字（0~10）描述：**适合作为宠物的程度**、**飞行能力**。

| 词 | 宠物度 | 飞行能力 |
| ---- | ---- | ---- |
| 猫 | 9 | 0 |
| 鹦鹉 | 8 | 9 |
| 虎皮鹦鹉 | 8.5 | 9 |
| 汽车 | 0 | 0 |

于是每个词不再是孤立符号，而是**空间中的一个坐标**：位置越近 = 特征越相似；从原点拉一条带方向的箭头指向该点，这条**有方向的线段就是向量**（高中数学那个向量）。**用一组数字表示一个词 = 词向量。**

### 3.2 余弦相似度

衡量「两个词有多像」的常用方法不是看两点距离，而是**比方向**：方向越接近、夹角越小，余弦相似度越高，语义越相似。

$$\cos\theta = \frac{\vec{a}\cdot\vec{b}}{\lVert\vec{a}\rVert\,\lVert\vec{b}\rVert}$$

> 🎯 「两个词像不像」这件抽象的事，被变成了一道**可以精确计算的数学题**。

### 3.3 从 2 维到几千维，从人工设计到自动学习

2 维描述一个动物都不够（还得考虑是否哺乳、体型、食肉、栖息地），描述通用词要几十维、几百维甚至上千维。我们画不出也想象不出几千维超空间，但**计算方式和 2 维、3 维没有本质区别**。

关键转折：维度全由人设计工作量巨大且覆盖不了复杂抽象关系，所以——**人只设计维度数量，数值交给计算机自己学**。

学的方式：经常出现在相似上下文中的词，含义通常接近。

> 「轩辕养了一只鹦鹉」/「轩辕养了一只虎皮鹦鹉」/「给鹦鹉喂食」/「给虎皮鹦鹉喂食」——鹦鹉和虎皮鹦鹉总出现在相似位置、搭配相似的词，训练中它们的向量就会逐渐靠近。

训练完：猫狗兔子距离较近，鹦鹉和虎皮鹦鹉更近，汽车远远在外。

**用一组连续数字表示词语的方法 = word embedding（词嵌入）。**

单个数字通常解释不出含义，但**整组数字作为整体**，就是这个词在高维语义空间中的位置。

> 💬 视频原话感慨：数学不止能计算日月星辰的轨迹，还能描述人类语言这样抽象的东西。在他看来看，**词向量的发明甚至比 Transformer 架构更重要**——没有词向量，NLP 还停留在统计数数的阶段。

词向量带来的**泛化能力**：训练数据里从没出现「养了一只虎皮鹦鹉」，但模型靠「虎皮鹦鹉的向量挨着鹦鹉」就能判断这是合理组合。

> ⚠️ 但光有词向量还不够：n-gram 是基于文本字符串统计的，**根本没用到语义**，所以得换技术。

## 四、前馈神经网络：吃语义，学规律

神经网络最擅长提取抽象特征做计算（图像识别已证明过），于是：喂大量文章，让它通过训练找到一组合适的权重和偏置，**拟合语言中的规律**——不再是单纯数数。

**前馈神经网络 = 一条从输入到输出的单向计算流水线**：输入层 →（一个或多个隐藏层做加权求和 + 非线性变换）→ 输出层。

### 4.1 猜词任务怎么跑

| 步骤 | 内容 |
| ---- | ---- |
| 输入 | 前 3 个词「轩辕 养了 一只」 |
| 向量化 | 每个词 300 维 → 3 × 300 = **900 维**输入 |
| 计算 | 逐层加权求和 + 非线性 |
| 输出 | 词表中每个词一个分数（猫 ？狗 ？鹦鹉 ？汽车 ？） |
| 归一化 | softmax 变概率 → 选最高 |

### 4.2 比 n-gram 强在哪

1. **进网络的是带语义的词向量**，不是互不相关的符号。鹦鹉和虎皮鹦鹉向量接近 → 进入网络后计算结果相似 → 在鹦鹉上学到的规律有机会**推广**到虎皮鹦鹉。
2. **隐藏层 + 非线性**能学到比数数更复杂的规律，比如「养了一只→宠物」「飞来的一只→鸟类」「开来了一辆→汽车」。这些规律不用人逐条写，训练中自己调参数学出来。

### 4.3 墙三：固定窗口

输入层设计成接 3 个词，就只能看前 3 个；想让它看 5 个就得**重新设计输入层**。3 个、5 个、10 个——**上下文长度永远是固定的**。

长句测试：「轩辕小时候养过一只虎皮鹦鹉 / 它有绿色的羽毛 / 还会模仿人说话 / 后来轩辕去了外地上学 / 很多年没有再见到它 / 但他始终记得小时候养过的那只 ____」

- 人：靠**记忆**，第一句就给了答案；
- 固定窗口模型（比如只能看 5 个词）：虎皮鹦鹉早已超出窗口，**对它来说就像从没出现过**。

> 「前馈神经网络解决了泛化的问题，却没有解决**记忆长度**的问题。」

## 五、RNN：加一份会传递的记忆

**核心新增：隐藏状态（hidden state）**，一份可以不断向后传递的信息，可理解成模型的记忆。

它不是记事本，不会写下「刚才读到了轩辕」。**隐藏状态的本质仍是一组数字、一个向量**——正如词向量编码词义，隐藏状态编码「到目前为止读到的内容」。单个数字仍难解释，但组合起来就是模型对已读内容的**压缩表示**。

### 5.1 逐步计算

| 步骤 | 输入 | 计算 | 得到 |
| ---- | ---- | ---- | ---- |
| 起始 | 无前文 | 准备初始隐藏状态 | h₀ |
| 读「轩辕」 | 词向量 + h₀ | 加权求和 + 非线性 | h₁（记忆 1.0，含轩辕） |
| 读「养了」 | 养了的向量 + h₁ | 同上 | h₂（记忆 2.0，含轩辕 + 养了） |
| 读「一只」 | … | 同上 | h₃ |
| … | … | 每个 token 刷新一次 | 直到句末 |

$$h_t = f(W\,x_t + U\,h_{t-1} + b)$$

最终隐藏状态一方面传给下一个位置，一方面交给输出层完成当前预测。

> 📌 结构图里画的那一串 RNN 单元，其实是**同一套参数**反复使用——同一个神经网络被连续调用了很多次，每次处理一个 token。

### 5.2 比前馈强在哪

前馈输入固定 3 个，第 4 个词进不来；RNN 能不断读新 token 并把隐藏状态往后传，**理论上句子多长，前面内容都有机会影响后面结果**。

### 5.3 墙四：长期依赖

**问题 1：记忆会在传递中被冲淡。** 隐藏状态维度固定——不管句子 10 个词还是 100 个词，都得把前文压进同样大小的一组向量。新内容不断涌入，旧信息容易被覆盖；传递距离越长，最早的信息越模糊。读到句尾时，「虎皮鹦鹉」的特征可能已经非常微弱。

> RNN 比较容易记住**附近**的内容，却很难稳定记住几十甚至几百个 token 之前的信息——这就是**长期依赖问题**。

**问题 2：不只是记不住，还学不会。** 训练时要知道前面某条信息重不重要，得等很多 token 之后预测出错才知道；误差再一路反向传回去，经过几十次计算，信号很容易越来越弱。

## 六、LSTM：给记忆开一条 VIP 通道

改造思路：原来的隐藏状态照旧负责当前计算，**另外加一条专门传重要信息的通道**，这条通道尽量少做复杂修改，让重要信息能稳定地一路往后传。

> 例：读到「轩辕小时候养过一只虎皮鹦鹉」，这条信息后面还要用 → 写进 VIP 通道；后面「它有绿色的羽毛」「会模仿人说话」「去外地上学」新信息不断进来，但「养的是虎皮鹦鹉」可以继续保留；几十个 token 后遇到「但它始终记得小时候养过的那只」，把保存的信息取出来。

### 6.1 但什么都往里写，通道照样会被搞乱 → 加三道门

模型必须学会判断三件事：**哪些旧东西没用了可以忘** / **哪些新东西值得写** / **预测时该取哪些用**。

| 门 | 作用 |
| ---- | ---- |
| **遗忘门** | 决定之前保存的每部分信息**还要留多少**——模型需要有能力删除过去没用的信息 |
| **输入门** | 决定当前 token 的新信息**要不要写进长期记忆**、写多少 |
| **输出门** | 决定当前这一刻，长期记忆里**哪些内容该拿出来用** |

于是每读一个 token，模型不再只是把隐藏状态整个重算一遍，而是额外计算「旧的哪些继续留、新的哪些加进去」——**长期记忆被有选择地更新**。

### 6.2 门是怎么学会开关的

不是程序员一条条写规则。**门控计算本质是一组可学习参数**：根据当前输入与之前状态算出一串 **0~1 之间的数字**，所谓「门开多大」就由这些数字控制。

学习靠训练：喂大量完整文本，不停做猜词题。

> 「轩辕小时候养过一只 ___」→ 虎皮鹦鹉；「它有绿色的 ___」→ 羽毛；……「他依然记得小时候养过的那只 ___」→ 虎皮鹦鹉。

初始参数是乱的，模型可能没存好、或存好了但被遗忘门削弱，最后预测成「猫」→ 与标准答案不符 → 产生预测误差 → **反向传播**调整整个网络参数（包括三道门）。若模型发现「前面把虎皮鹦鹉保存得更好，最后这个词就预测得更准」，参数就会往这个方向调。

训练久了：读到「某人养了一只某种宠物」，输入门更倾向把「宠物是什么」写进去；隔了很多内容但这条信息仍可能有用，遗忘门更倾向保留；需要再提这只宠物时，输出门把信息取出来。

> 🎯 **不是我们提前告诉模型「虎皮鹦鹉很重要，记住它」，而是模型在一次一次预测错误、修改参数的过程中自己学会了什么样的信息值得长期保存。**

### 6.3 命名

| 概念 | 术语 |
| ---- | ---- |
| 改造后的 RNN | **LSTM**（Long Short-Term Memory，长短期记忆网络） |
| 那条长期记忆 VIP 通道 | **cell state（细胞状态）** |

很长一段时间里 LSTM 是 NLP 的主力：机器翻译、语音识别、文本生成都大量用过它。

### 6.4 墙五：顺序计算 + 远距离仍绕路

1. **必须串行。** 得先读完「轩辕」得到隐藏状态才能处理「养了」，处理完「养了」才能处理「一只」。前一个 token 没算完，后一个无法开始 → **句中大量 token 无法同时计算**，训练效率提不起来。数据越来越多、模型越来越大时，这个瓶颈非常明显。
2. **远距离信息仍要绕路。** 最后那个「那只」和最前面的「虎皮鹦鹉」有直接关系，但在 LSTM 里信息仍须经过中间所有 token 一步步传递。

## 七、于是就有了三个问题（通向 Transformer）

1. 能不能让最后那个「那只」**直接去查看**前面的「虎皮鹦鹉」？
2. 能不能让一句话中**每一个 token 都直接寻找跟自己最相关的其他 token**？
3. 能不能在理解句子时**同时处理所有 token**，不再沿固定链条依次等待？

> 顺带还留下一个坑：**没有了 RNN 和 LSTM 之后，模型又是怎么知道 token 的先后顺序的？**

这三个问题 + 一个坑，就是下一期的全部内容：注意力机制、QKV、位置编码，一步步搭出完整的 Transformer。

## 术语速查

| 术语 | 一句话 |
| ---- | ---- |
| token | 模型读写文本的基本单位（词 / 汉字 / 标点 / 子词片段） |
| n-gram | 只看前 n−1 个词的统计式预测 |
| 词向量 / word embedding | 用一组连续数字（向量）表示词的语义 |
| 余弦相似度 | 比向量方向而非距离的相似度度量 |
| 前馈神经网络 | 单向流水线：输入层 → 隐藏层 → 输出层 |
| 隐藏状态 | RNN 中不断更新的向量，是对已读内容的压缩摘要 |
| 长期依赖 | 序列过长时早期信息被覆盖、梯度传不回去 |
| cell state | LSTM 的长期记忆通道 |
| 门控 | 用 0~1 的可学习系数控制信息保留 / 写入 / 读出 |
