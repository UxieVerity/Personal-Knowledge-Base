## 二、贯穿六期的一条主线（推荐按这个顺序读）

```
【第 1 期】加权求和 + 激活函数           → 神经网络 = 一个拟合函数
        ↓  这个函数吃不了文字符号
【第 2 期】n-gram → 词向量 → FFN → RNN → LSTM
        ↓  LSTM 卡在「串行」和「远距离传话」
【第 3 期】自注意力 → QKV → 多头 → 位置编码 → FFN
          → 残差 → 掩码 → 交叉注意力 = Transformer
        ↓  transformer 一个 token 一个 token 生成，重复计算太多
【第 4 期】KV Cache：历史 token 别再重算
        ↓  缓存在这次请求结束时被释放，下次还得重算
【第 5 期】Prompt Cache：把缓存跨请求复用 → 前缀必须稳住
        ↓  缓存和计算量都随上下文线性/平方膨胀
【第 6 期】MQA/GQA（少存几套）→ MLA（压窄）
          → DSA（别全看）→ CSA（压短）
```

## 三、每期的一句话抓手

### 1. 神经网络：线性叠层等于一层，非线性才掰弯直线

「加权求和 → 减阈值 → 过激活函数」= 一个神经元。把直觉量化成数字、加权求和、减门槛、softmax 变概率，一路推下来，最后发现真正的转折点是**激活函数**：没有它，叠一百层还是一次函数。

### 2. 五堵墙与五次翻墙

| 阶段 | 撞的墙 |
| ---- | ---- |
| n-gram | 组合爆炸 + 只认符号不认语义 |
| 词向量 | 单独用不能预测 |
| 前馈网络 | 固定窗口 |
| RNN | 长期依赖（旧信息被覆盖、梯度传不回去） |
| LSTM | 只能串行 + 远距离仍要绕路 |

### 3. Transformer：结构图不用背，问题一路推

自注意力（QKV）→ 多头（一套不够）→ 位置编码（并行丢了顺序）→ FFN（光找信息不够，还得消化）→ 残差连接（层深了梯度消失）→ 掩码自注意力（生成不能偷看未来）→ 交叉注意力（解码器要读原文）。

### 4. KV Cache：翻转点在「历史看不到未来」

因果掩码 ⇒ 新 token 不改变历史结果 ⇒ 历史 O、FFN、整条链路都不用重跑。**只存 K 和 V**：Q 是一次性查询；O 是「我拿到的」而非「我能给的」。代价是显存随`层数 × 上下文长度`线性膨胀。

### 5. Prompt Cache：Agent 开发者的账单纪律

KV Cache 管「这一次请求别重复算」，Prompt Cache 管「这一次和上一次别重复算」。**只有前缀能命中**，所以：靠前部分不变、工具定义别乱动、历史只追加不修改、别做滑动窗口裁剪、压缩别太频繁。**上下文短一点不一定更省钱，前缀稳住了长一点反而更便宜。**

### 6. 长上下文：六个缩写 = 六个省钱方向

| 缩写 | 省什么 |
| ---- | ---- |
| MHA | 基线（每头一套 KV） |
| MQA | 所有头共用一套 KV |
| GQA | 每组头共用一套 KV |
| MLA | 横着压：每 token 存 latent，用时按头展开 |
| DSA | 别全看：indexer 初筛 + top-k 精算 |
| CSA | 竖着压：多个位置合成一条，再挑着看 |

**「百万上下文用一半就降智」的根因**：省钱的办法大多不是白省的，压缩丢信息、筛选可能漏关键；**每一份省下来的算力，都是拿精度换的**。
