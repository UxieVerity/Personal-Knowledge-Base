# 01 · 从一个猜水果的游戏，一步步搞懂神经网络

> **结论先行**：神经网络不是什么神秘黑箱，它就是**「加权求和 → 减阈值 → 过激活函数」**这一个小单元，成排成层堆起来的结果。全片是一条「被逼出来」的推导链：把人的直觉量化成数字 → 加权求和打分 → 减阈值变成正负判断 → softmax 把分数变成概率 → 发现「一刀切」表示不了夹在中间的情况 → 加层没用（线性叠加还是一次函数）→ 只有塞进**激活函数**才能把直线掰弯 → 于是神经元、层、神经网络这几样东西被「发明」出来了。一句话：**线性只负责搬数据，非线性才负责拟合世界。**

## 一、起点：让计算机玩「猜水果」

盒子里有水果，给四条线索：**红色、很甜、个头中等、水分不多** → 人秒答「苹果」，因为西瓜是绿的、香蕉是黄的、葡萄太小。

计算机的问题在于：它不懂「中等」「不是特别多」是什么。所以第一步必须**量化**——每条线索打成 1~10 分：

| 线索 | 打分（某苹果） |
| ---- | ---- |
| 颜色红 | 9 |
| 甜度 | 7 |
| 个头 | 5 |
| 水分 | 5 |

再把「猜是哪种水果」拆成四个**是/否**子任务（是葡萄吗 / 是苹果吗 / …），问题就简化成二分类。

## 二、人的直觉其实就是「加权求和」

回想你自己怎么判断的：又红又甜最像苹果，所以颜色、甜度分量重；大小、水分只是参考。把这份「分量」也量化成权重：

| 线索 | 分值 x | 权重 w |
| ---- | ---- | ---- |
| 颜色 | 9 | 7 |
| 甜度 | 7 | 6 |
| 个头 | 5 | 3 |
| 水分 | 5 | 3 |

$$9\times7 + 7\times6 + 5\times3 + 5\times3 = 135$$

> 💡 视频特意强调：这些权重和分数都是**拍脑袋定的**，换一组也完全可以。现在不用纠结数值，只要 get「加权求和」这个形式。

### 门槛（偏置）

135 分算高吗？还缺一条门槛线。拿一个明显不是苹果的青果子（又小又绿又酸）同样算一遍得 44 分，两者取平均 90 作为门槛：

- 135 > 90 → 是苹果
- 44 < 90 → 不是

每次都要跟 90 比很别扭，于是**把门槛塞进公式**（移项）：

$$\underbrace{\sum_i w_i x_i}_{加权求和} - \underbrace{90}_{门槛} > 0 \;\Rightarrow\; 是苹果$$

这就是神经元的雏形：**加权求和 + 偏置 + 符号判断**。

## 三、从「是 / 否」到「概率」：softmax

四个子任务各自出分（比如苹果 45、西瓜 30、香蕉 -10、葡萄 -15），要汇总成一个结论。

- 直接「谁分高选谁」能用，但**分数代表几成把握看不出来**；
- 想换算成百分比 → 每个分数除以总和即可，**但分数有正有负**，占比会算歪；
- 取绝对值也不行：+45 和 -45 绝对值一样，含义却相反。

**解法：先过指数函数，再归一化。**

| 分数 | 过指数后 | 归一化 |
| ---- | ---- | ---- |
| 45 | 大正数 | 占比最高 |
| 30 | 正数 | 次之 |
| -10 | ≈0 | 极小 |
| -15 | ≈0 | 极小 |

指数函数的好处：输入正 / 负 / 零，输出恒正；负得越多越贴近 0，正得越多被放大。除以总和后，四项加起来正好 100%。

> 这套「**先取指数、再归一化**」的操作就叫 **softmax**，是大模型输出层词表概率分布的同一个东西。

## 四、撞墙：加权求和天生「一根筋」

真正的苹果，个头是**中等**——太小不是，太大也不是。但加权求和里「个头越大 → 越倾向是苹果」，来一个 10 分的超级大果，得分反而比 5 分的真苹果还高，机器会更起劲地判它是苹果。**错了。**

把问题简化到只看一个维度（个头），判断公式就是**一次函数**：

- 一次函数画在平面上是一条直线，一刀把平面切成两半，只能表达「大于某个值 / 小于某个值」；
- **永远切不出「夹在某个区间中间」的那一段**；
- 加第二个维度 → 二元一次函数 → 三维空间里的一个**平面**，还是直的，问题照旧；
- 再加维度只能靠想象，道理不变。

### 那多叠几层行不行？

直觉：一层只会切一刀，那我叠很多层，合起来总能切出复杂形状吧？

不行。只看一维，第一层加权求和，第二层对结果再加权求和，合并化简后**仍是一次加权求和**：

$$w_2(w_1 x + b_1) + b_2 = \underbrace{w_2 w_1}_{w'} x + \underbrace{(w_2 b_1 + b_2)}_{b'}$$

**叠两层 = 一层，叠一百层还是一层**，除了多烧算力什么也没改变。

## 五、破局：激活函数把直线「掰弯」

必须有一个函数接在加权求和之后，把**线性传导**变成**非线性传导**，直线才会被掰弯。

用最简单的非线性函数——**阶跃函数**（<0 出 0，>0 出 1），两层搞定「个头在 4~6 之间才是苹果」：

| 层 | 单元 | 作用 |
| ---- | ---- | ---- |
| 第一层 A | 个头 − 4 过阶跃 | 判断「够大了吗」，>4 出 1 |
| 第一层 B | 个头 − 6 过阶跃 | 判断「太大了吗」，>6 出 1 |
| 第二层 | A − B | 最终分 |

代入验证：

| 个头 | A | B | A−B | 判断 |
| ---- | ---- | ---- | ---- | ---- |
| 2（太小） | 0 | 0 | 0 | 不是 |
| 5（正常） | 1 | 0 | 1 | 是 |
| 8（太大） | 1 | 1 | 0 | 不是 |

**中间那一段被两台判断器轻松框出来了。**

反过来验证非线性有多关键——把阶跃函数撤掉重算：

$$A - B = (x-4) - (x-6) = 2$$

永远等于常数 2，什么也判断不了。这正是第四节「叠层 = 一层」的同一个病根。

> 🎯 **点睛之笔**：非线性的一掰，解决了线性解决不了的问题。直来直去很多时候解决不了问题，有所变通才能更好拟合这个世界。接在加权求和后面的这个非线性函数，就叫**激活函数**（常见：阶跃、Sigmoid、Tanh、ReLU…）。

## 六、术语落地：刚才造出来的就是神经网络

| 术语 | 对应上文 |
| ---- | ---- |
| **神经元** | 最小判断单元：几个输入各乘权重、求和、减门槛、过激活函数。灵感来自生物神经元「攒够信号再激发」 |
| **层** | 一批神经元并排站成一排 |
| **输入层 / 隐藏层 / 输出层** | 最前一层 / 中间若干层 / 最后一层 |
| **神经网络** | 很多层叠起来，前一层的输出喂给后一层 |

**把神经网络理解成一个函数**——和中学学的函数没本质区别，都是「输入参数 → 映射到结果集」，只是没法用一个具体数学表达式写出来，而是靠无数个线性 + 非线性计算拼出来。

## 七、还差最后一步：训练

到这儿它还是个玩具：权重、偏置全是拍脑袋定的，换个产地、换批苹果就全不对了。

正解是别靠经验，去找一堆各种苹果，把四个维度提出来挨个喂进去，**不断调整权重和门槛直到能完美契合所有样本**。但人工调不现实：

- 本例才 4 个维度，真实网络输入成千上万；
- 多层叠加嵌套后，参数量是天文数字。

所以要让**机器自己调参数**——这个过程就是**神经网络的训练**（下一期内容）。

## 八、给 LLM 学习者的三个锚点

1. **「函数」这个观念要一直带着走。** 后面 Transformer 的每一个 block，本质还是「线性映射 + 非线性激活」的堆叠，只是把输入从 4 个水果特征换成了 token 的向量。
2. **softmax 你先见过了。** 输出层把 logits 变成词表概率分布用的就是它，这里已经完整推过一遍。
3. **「线性叠层等于一层」这条代数事实**，是理解为什么必须有激活函数、为什么残差连接与归一化很重要的地基。
