# JS 闭包与作用域 · 面试速记

> 闭包是 JS 核心**必问**。本速记覆盖「定义 → 为什么存在 → 词法作用域 → 陷阱 → GC → 用途」主线，30 秒能讲完，详细见 [[闭包与作用域链、执行上下文]]。

---

## 1. 一句话定义（背诵版）

> **闭包 = 函数 + 它创建时的词法环境（Lexical Environment）的引用。** 内部函数被返回/传递出去后，仍持有外层函数词法环境的引用 → 外层变量「被带走、不销毁」。

**为什么 JS 必然有闭包**：函数是**一等公民**（可当返回值/参数传）+ **词法作用域**（看在哪定义，不看在哪调用）→ 函数被传走时它的环境必须跟着走。**这不是刻意设计，是这两条基础规则的必然推论**（Python/Ruby/Kotlin 都有）。

## 2. 核心机制（30 秒版）

| 概念                | 一句话                                   |
| ----------------- | ------------------------------------- |
| 词法环境              | `{变量→值}` 容器 + outer 引用，**每次函数调用新建一份** |
| `[[Environment]]` | 函数对象内部指针 → 创建时的环境，**永不改变**            |
| 作用域链              | 从当前环境沿 outer 逐层向外找，直到全局               |

**关键结论**：
- 每次调用外层函数 → **一份独立环境**，多个闭包互不影响（`c1()=3, c2()=1`）
- `var` 函数级作用域：for 循环**只创建一个变量**，全捕获同一个 → `[3,3,3]`
- `let` 块级作用域：**每轮迭代新环境** → `[0,1,2]` ← 经典陷阱，背下来

## 2.5 块级作用域 vs 函数级作用域（定义背下来）

| | `var`（函数级） | `let`/`const`（块级） |
| ---- | ---- | ---- |
| 作用域边界 | 所在**函数** | 最近的一对 `{}`（if/for/switch…） |
| 提升 | 有，初始化为 `undefined` | 词法提升但进 **TDZ**，声明前访问报 `ReferenceError` |
| 重复声明 | 允许 | `SyntaxError` |
| 全局声明 | 挂 `window` | 不挂 `window` |

**一句话定义**：函数级作用域 = 变量可见范围是「声明它的那个函数」，`var` 会**逃出 `{}` 块**；块级作用域 = 可见范围是「最近的一对 `{}`」，`let`/`const` 出块即不可见。**为什么这么设计**：`var` 生命周期超出所在块 → 循环捕获全部共享同一个变量；`let` 让生命周期精确匹配代码块，把「声明前使用」从静默 `undefined` 变成显式报错（TDZ）。

## 3. 闭包与 GC（面试最爱追问）

- **被闭包真正引用的变量 → 阻止 GC**，用后主动断开（`= null` / `removeEventListener`）
- **V8 无谓捕获优化**：闭包没引用的外层变量不锁（实测 `[D-gc]` 已回收）
- 泄漏三场景：事件监听器不移除 / `setInterval` 忘 `clearInterval` / 全局挂大对象
- 一句话：**GC 只看可达性，不看你函数返没返回**

## 4. 三大用途（必背三例）

| 用途 | 例子 | 一句话 |
| ---- | ---- | ---- |
| 私有变量 | 计数器 | `count` 只能通过返回的函数改 |
| 柯里化 | `x => y => x + y` | 分次捕获参数，每次调用生成新闭包 |
| IIFE 模块化 | `(() => { let n; return {get, set} })()` | ES Module 前的主流封装 |

## 5. 高频追问速答

- **闭包是什么？** 函数 + 创建时词法环境的引用，函数返回后仍能访问外层变量
- **为什么能访问？** 函数持有 `[[Environment]]`，沿作用域链查找
- **会内存泄漏吗？** 被引用的变量阻止 GC；V8 只锁真正被引用的，用后 `= null`
- **var / let 循环区别？** var 全捕获同一个；let 每轮新环境
- **每次调用同一份吗？** 不是，每次调用外层函数创建新环境

> 30 秒完整版：**闭包 = 函数 + 出生时环境的引用**。一等公民 + 词法作用域 → 必然存在。每次调用独立环境；`var` 全捕获（for 陷阱）、`let` 每轮新绑定。内存：只有被真正引用的变量阻止 GC（V8 无谓捕获优化），用后 `= null`/移除监听。用途：**私有变量 / 柯里化 / IIFE 模块化**。
