
前端开发岗位
岗位定位

我们正在把 Studio 从视频创作"工具"进化成"AI 创作平台"。这里不止一种创作方式，而是覆盖多种创作模式的完整创作体系。你将作为 Studio 创作体系的核心研发，负责把创作、编辑、智能生成、3D 可视化、多人协作等能力做成稳定、流畅、智能的产品，并能扎进不同创作模式持续做深、打磨。每一种创作模式都在走向 Agentic 化——每一次用户操作背后，都有 AI 在参与理解、生成与迭代。

核心职责

1. 创作模式能力建设

● 负责 Studio 多种创作模式的核心能力研发与工程建设，扎进各创作模式持续做深、做好，打磨极致的用户创作体验，构建产品的核心竞争力。

● 覆盖从故事板、自由画布到 Agent创作、智能剪辑等多种创作模式的建设，能根据方向重点灵活切入，把不同创作模式都做到好用、易用。

2. 让各创作模式更 Agentic

● 推动 AI Agent 深度融入每一种创作模式，让创作从"人操作工具"走向"人与 Agent 协同创作"，把各创作模式整体带向更 Agentic 的形态。

● 设计 Agent 参与创作的交互方式，让 AI 的理解、生成与调整过程对用户清晰可见、可控可干预，把不确定的生成过程做成顺畅、可信赖的创作体验。

3. 图形渲染、音视频与 3D 能力建设

● 基于 Canvas / WebGL / WebGPU / OffscreenCanvas / WebAssembly / WebCodecs 等技术，建设高性能渲染与实时预览能力。

● 负责音视频基础能力，包括播放、剪辑、转码、封装格式、字幕、音轨、流媒体协议、解码与处理链路。

● 参与 3D 资产预览、空间编辑、镜头控制、实时渲染等方向的能力建设，探索 Mesh / 点云 / NeRF / 3D Gaussian Splatting 等新型 3D 表达在创作场景的落地。

4. 多端适配与多站点

● 支持浏览器端、桌面端（Electron / Tauri）等多种运行环境，保障不同设备、分辨率、浏览器和网络条件下的一致体验。

● 参与国际化、多语言等基础能力建设，支撑国内站 / 国际站 / 海外独立站等多站点的统一技术架构。

5. 性能与体验保障

● 从用户体验出发，持续提升各终端的性能与创作流畅度，优化加载速度、交互响应、渲染稳定性与弱网体验，让复杂创作也能顺滑好用。

● 建设产品质量与稳定性保障，覆盖监控、异常定位、自动化测试等能力，保障产品长期稳定迭代。

职位描述
基础条件

1. 计算机、软件工程、数字媒体、图形学、多媒体技术等相关专业本科及以上学历。

2. 3 年以上 Web 或跨端应用研发经验，熟练掌握 TypeScript / JavaScript，具备扎实的工程能力和良好的代码质量意识。

3. 具备独立完成复杂 Web 应用从架构设计到上线交付的能力，有大型工程化实践经验。

4. 有复杂交互产品、编辑器产品、创作工具、音视频工具、图形渲染或生产力工具研发经验优先。

核心技术能力

1. 熟悉 React / Vue / Next.js 等前端框架，有 Electron / Tauri 等桌面端 / 跨端工程经验，工程化、状态管理、性能优化与跨环境兼容能力扎实。

2. 熟悉 Node.js 或至少一门服务端语言，具备从前端到接口层独立闭环的全栈能力。

3. 熟悉 Canvas / WebGL / WebGPU / WebAssembly / WebCodecs 中至少两项，有 2D/3D 图形渲染或可视化编辑器经验。

4. 熟悉音视频基础能力（播放、剪辑、转码、封装、字幕、流媒体协议、解码等任一方向），有相关工具开发经验优先。

5. 有 LLM 或 Agent 系统开发经验，熟悉 Function Calling / Tool Use / MCP 等范式，能将 AI 能力融入产品交互。

加分项

1. 有视频剪辑、在线设计、白板协作、图像编辑、3D 编辑器等创作类产品的核心研发经验。

2. 有 Agent 产品、AIGC 或内容创作类产品经验，尤其在工作流可视化、人机协同交互方向。

3. 有 Three.js / Babylon.js / PlayCanvas 等 3D 引擎经验，或 Mesh / 点云 / NeRF / 3D Gaussian Splatting 等 3D 图形技术经验。

4. 有国际化 / 海外 SaaS 产品经验，或对视频美学、镜头语言、剪辑节奏、互动叙事有理解。

我们期待的你

1. AI 工程思维：把 AI 能力当作平等的技术栈之一，善于将模型、Agent、工具链与产品体验自然融合；遇到问题时不受限于层次边界，能够把问题解到位。

2. 创作产品工程师：理解创作不是表单提交，而是持续试错、调整、预览和迭代；对"让创作更简单"有执念，热衷于把专业级能力做成普通人也能用的产品。

3. 体验型研发：对画面质量、性能、交互体验有天然的敏感度，代码有结构、UI 有美感，能把复杂能力做得顺手。

4. 技术好奇心强：愿意持续探索 Agent 交互、新渲染方式、新音视频能力、新 3D 表达和跨端技术，乐于钻研更优的技术方案。

5. 跨界协作者：能与算法、产品、设计、PD、国际化团队高效协作，共同定义下一代视频创作范式。
