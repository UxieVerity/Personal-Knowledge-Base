Update Rendering 阶段：scroll / resize / rAF / RO / IO 顺序实测

每个渲染帧内五类事件的真实派发顺序。日志带帧号标记，验证「谁先谁后」。
规范顺序 (HTML Living Standard §8.1.7.3 update the rendering)： resize 事件 → scroll 事件 → rAF 回调 → 样式/布局 → ResizeObserver 递送 → IO 交叉计算 → Paint
要点：resize / scroll 事件在 rAF 之前派发；RO 在 rAF 之后；IO 计算在渲染内、回调异步派发。
事件本 demo 如何触发派发时机

rAF每帧自动执行step 14
ResizeObserver每帧抖动 box 宽度step 16（rAF 之后、layout 之后）
