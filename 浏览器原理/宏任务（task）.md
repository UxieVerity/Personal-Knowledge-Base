### 宏任务（task）

- 定时器：`setTimeout`、`setInterval`
- I/O：网络请求回调（`fetch`/`XHR`）、File API
- 用户交互事件：`click`、`keydown`、`scroll`、`input` 等
- 消息通道：`MessageChannel`/`postMessage`、`BroadcastChannel`
- DOM 事件派发：`dispatchEvent`
- 加载类：`load`、`DOMContentLoaded`
- 历史遍历：`hashchange`、`popstate`
- 初始脚本：页面第一个 `<script>`
