## A. 主题复述（8 题，每题 30 秒）

### 1. 什么是闭包？为什么 JS 必然有闭包？
> 答案要点：闭包 = 函数 + 它创建时词法环境的引用。函数是一等公民（可返回/传递）+ 词法作用域（看定义处不看调用处）→ 函数被传走时环境必须跟着走，这是两条基础规则的必然推论，不是刻意设计。

### 2. 闭包为什么能访问外层变量？
> 答案要点：函数对象持有内部指针 `[[Environment]]` 指向创建时的环境，沿作用域链（当前环境 → outer → 全局）逐层查找。

### 3. 每次调用闭包函数，环境是同一份吗？
> 答案要点：不是。每次调用外层函数新建一份词法环境，多个闭包互不影响（`c1()=3, c2()=1`）。

### 4. `var` 和 `let` 在 for 循环里的区别？为什么？
> 答案要点：`var` 函数级作用域，循环只创建一个变量，闭包全捕获同一个 → `[3,3,3]`；`let` 块级 + 每轮迭代新环境 → `[0,1,2]`。经典陷阱。

### 5. 闭包会造成内存泄漏吗？V8 有什么优化？
> 答案要点：会——被闭包真正引用的变量阻止 GC（可达性不看函数是否返回）。但 V8 有捕获优化：闭包没引用的外层变量不锁，可被回收。用后主动断开（`= null` / 移除监听）。泄漏三场景：事件监听器不移除、setInterval 忘 clear、全局挂大对象。

### 6. 闭包的三大用途？
> 答案要点：私有变量（计数器）、柯里化（`x => y => x+y`）、IIFE 模块化（ES Module 前的主流封装）。

### 7. `var` 提升 vs `let` TDZ 是什么？
> 答案要点：`var` 声明提升到函数顶，初始化为 `undefined`；`let/const` 也提升但不初始化，声明前访问抛 `ReferenceError`（暂时性死区 TDZ）。

### 8. 执行上下文栈是什么？递归的代价？
> 答案要点：LIFO 栈，压入函数调用上下文、弹出返回。每个 EC 占内存、栈有上限（本机约 1.25 万层），递归要写终止条件，超深会 `RangeError: Maximum call stack size exceeded`。

## B. 手写题复述（4 题，先默写再对照）

### 9. 防抖核心代码？leading 版怎么判断冷却完？
> 答案要点：`clearTimeout(timer); timer = setTimeout(fn, delay)`。leading 用 `immediate && !timer`——timer 为 null = 冷却结束 → 立即执行。定时器回调会丢 this，先 `const ctx = this`。

### 10. 节流两种实现区别？
> 答案要点：时间戳版（leading，第一次立即执行，之后固定间隔）；定时器版（trailing，停止触发后 delay 执行最后一次）。防抖停后一次，节流间隔多次。

### 11. 深拷贝循环引用怎么处理？为什么先 map.set 再递归？
> 答案要点：WeakMap 登记已复制对象，遇环返回副本。必须先登记再递归——否则递归到自身时查不到 map 里没有，依然无限递归爆栈。WeakMap 弱引用不阻止 GC。

### 12. 扁平化递归版核心？超深数组怎么办？
> 答案要点：遍历，`Array.isArray` 是数组就递归拍平后 `...` 展开 push，否则 push。超深（1 万层）递归爆栈，改迭代版（显式栈 + 逆序 reverse）。
