# 居中方案全集（5 法对比）

> **结论：水平居中 3 法（text-align / margin auto / flex）+ 垂直居中 4 法（line-height / flex / absolute+transform / grid）+ 水平垂直全居中推荐 2 个**——**① `flex`（justify-content: center + align-items: center）最简单万能；② `absolute + inset: 0 + margin: auto`（需已知宽高）或 `transform` 平移（不需已知宽高）。** 面试要点：**flex 是首选（一行代码）；absolute+transform 适合「不知道子元素尺寸」；margin: auto 水平居中要求「块级 + 定宽」。**
>
> 可运行验证：[[CSS综合-demo.html]]（浏览器实测：居中 / Grid 自适应列数 / 两栏三栏 / 层叠陷阱 / transform-vs-left 动画 / 响应式断点）

## 1. 一句话速览（背诵版）

| 场景 | 推荐写法 | 特点 |
| ---- | ---- | ---- |
| 水平居中-行内 | `text-align: center` | 最简单，只管行内元素 |
| 水平居中-块级 | `margin: 0 auto` | 需定宽 |
| **水平垂直居中-首选** | `display: flex; justify-content: center; align-items: center` | **一行代码，无需知道尺寸** |
| 水平垂直居中-未知尺寸 | `position: absolute; top:50%; left:50%; transform: translate(-50%,-50%)` | 不需知道子元素宽高 |
| 水平垂直居中-已知尺寸 | `absolute; inset:0; margin:auto` | 子元素需定宽高 |
| Grid 居中 | `display: grid; place-items: center` | 最简洁（现代浏览器） |

## 2. 五种方法详解

### 方法① Flex（首选，万能）

```css
.parent { display: flex; justify-content: center; align-items: center; }
```

- **优点**：一行代码、子元素不需要知道尺寸、不脱离文档流
- **适用**：绝大多数场景，现代布局首选

### 方法② absolute + transform（未知子元素尺寸）

```css
.child { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }
```

- **原理**：先让子元素左上角到父容器中心（top/left 50%），再用 transform 平移自身一半（-50%）
- **优点**：子元素尺寸未知也行（transform 百分比相对自身）
- **缺点**：脱离文档流；transform 可能影响其他视觉效果

### 方法③ absolute + inset: 0 + margin: auto（已知子元素尺寸）

```css
.child { position: absolute; inset: 0; margin: auto; width: 200px; height: 100px; }
```

- **原理**：absolute + inset:0 让子元素「四边都贴父容器」，margin: auto 在绝对定位下会平均分配剩余空间 → 居中
- **要求**：**子元素必须定宽高**（否则 margin auto 无效，会被拉伸）

### 方法④ 行内居中（text-align / line-height）

```css
/* 水平：父 text-align: center（子是行内/行内块） */
.parent { text-align: center; }
/* 垂直：父 line-height = 父高度（子是单行文本） */
.parent { line-height: 100px; height: 100px; }
```

- **适用**：文本/行内元素；单行文字垂直居中

### 方法⑤ Grid 居中（最简洁）

```css
.parent { display: grid; place-items: center; }
```

- `place-items` = `align-items + justify-items` 简写，一行居中
- **现代浏览器全支持，是最简写法**（面试加分：知道 place-items）

## 3. 水平居中 vs 垂直居中（分开记）

**水平居中**：
- 行内元素：父 `text-align: center`
- 块级元素：`margin: 0 auto`（需定宽）
- flex：`justify-content: center`

**垂直居中**：
- 单行文本：`line-height = 高度`
- flex：`align-items: center`
- absolute+transform：`top: 50% + translateY(-50%)`

## 4. 为什么这么设计

- **为什么 margin: auto 能水平居中**：块级元素的 `margin-left/right: auto` 会自动吸收**剩余水平空间**均分到两侧 → 元素被推中间。但垂直方向**不能**（块级元素高度由内容决定，没有「剩余垂直空间」概念）——所以 `margin: 0 auto` 只水平居中。
- **为什么 absolute + margin auto 又能垂直**：absolute 定位让元素「脱离文档流 + 高度不再由内容决定」，`top:0; bottom:0` 给它一个明确的「可用空间」，margin auto 才能在垂直方向均分 → 居中。**脱离文档流是关键**。
- **为什么 transform 不依赖尺寸**：`translate(-50%)` 的百分比是**相对元素自身**的（不像 margin/left 相对父容器）——所以能平移「自身一半」，无需知道宽高。

## 5. 高频追问速答

| 问题 | 一句话答案 |
| ---- | ---- |
| 首选居中法？ | `display: flex; justify-content: center; align-items: center` |
| 子元素尺寸未知怎么居中？ | absolute + `translate(-50%,-50%)`（百分比相对自身） |
| 子元素尺寸已知怎么居中？ | absolute + `inset:0; margin:auto`（需定宽高） |
| margin: 0 auto 能垂直居中吗？ | 不能——块级高度由内容决定，无剩余垂直空间 |
| 为什么 transform 不依赖尺寸？ | translate 百分比相对元素自身 |
| Grid 一行居中？ | `display: grid; place-items: center` |
| 单行文本垂直居中？ | `line-height = 容器高度` |

## 6. 面试速记（30 秒版）

> **居中首选 Flex：`justify-content: center + align-items: center`（一行、无需尺寸）。** 子元素尺寸**未知**用 `absolute + top/left 50% + translate(-50%,-50%)`（transform 百分比相对自身）；**已知**用 `absolute + inset:0 + margin:auto`（需定宽高）。水平：行内 `text-align: center`、块级 `margin: 0 auto`（定宽）。**加分**：Grid 一行 `place-items: center` 最简洁；记住「margin auto 垂直不行，因为块级无剩余垂直空间；absolute 脱离文档流后才行」。
