# 响应式设计（媒体查询 / rem-vw / 移动端适配）

> **结论：响应式 = 一套代码适配所有屏幕，三大手段——① 媒体查询（`@media` 按断点改样式）；② 弹性单位（`rem`/`vw`/`%` 相对缩放）；③ 移动端适配（视口 meta / 流式布局 / 图片适配）。** 面试一句话：**「PC 用 px 固定，移动端用 rem/vw 弹性 + 媒体查询切断点，`meta viewport` 是移动端适配的前提。」**
>
> 可运行验证：[[CSS综合-demo.html]]（浏览器实测：居中 / Grid 自适应列数 / 两栏三栏 / 层叠陷阱 / transform-vs-left 动画 / 响应式断点）

---

## 1. 一句话定义（背诵版）

**响应式设计 = 用媒体查询 + 弹性单位 + 流式布局，让页面在手机/平板/桌面都能良好展示。**

| 手段 | 解决什么 | 关键语法 |
| ---- | ---- | ---- |
| **媒体查询** | 不同屏幕尺寸切换布局 | `@media (max-width: 768px) { }` |
| **rem/vw 弹性单位** | 字号/间距随屏幕缩放 | `rem` 相对根字号、`vw` 相对视口宽 |
| **视口 meta** | 移动端正确渲染（不缩放） | `<meta name="viewport">` |
| **流式布局** | 宽度自适应 | `%` / flex / grid 相对宽度 |
| **图片适配** | 图片不撑破/按需加载 | `max-width: 100%`、`srcset` |

## 2. 媒体查询（断点切换）

```css
/* 默认（PC）样式 */
.container { display: grid; grid-template-columns: 300px 1fr; }

/* 平板（≤ 1024px） */
@media (max-width: 1024px) {
  .container { grid-template-columns: 200px 1fr; }
}

/* 手机（≤ 768px）→ 单列 */
@media (max-width: 768px) {
  .container { display: block; }
}
```

**断点选择（面试常见）**：
| 断点 | 设备 |
| ---- | ---- |
| `> 1024px` | PC 桌面 |
| `768px - 1024px` | 平板 |
| `≤ 768px` | 手机横屏/大手机 |
| `≤ 480px` | 手机竖屏（老设备） |

> **面试点**：移动优先（`min-width` 从手机往上写）vs 桌面优先（`max-width` 从 PC 往下写）。**推荐移动优先**——默认手机样式，`@media (min-width: 768px)` 逐步增强，代码更简洁、性能更好（手机上不用加载桌面样式）。

## 3. rem / vw 弹性单位

| 单位 | 相对什么 | 特点 |
| ---- | ---- | ---- |
| **px** | 固定像素 | 不随屏幕变（PC 合适） |
| **rem** | **根元素（html）字号** | 改根字号全局缩放；配合媒体查询 |
| **em** | 父元素字号 | 易叠加混乱 |
| **vw/vh** | **视口宽/高**（1vw = 1% 视口宽） | 直接跟随屏幕 |
| **%** | 父元素宽/高 | 流式布局基础 |

**rem 适配方案（经典面试题）**：

```js
// 动态设置根字号：设计稿 375px 宽，1rem = 100px（方便换算）
function setRootFont() {
  const width = document.documentElement.clientWidth;
  document.documentElement.style.fontSize = width / 3.75 + 'px';  // 375 → 100px
}
window.addEventListener('resize', setRootFont);
setRootFont();
// 之后：设计稿 16px 的字 → 0.16rem
```

**vw 更简洁**：`1rem = 100vw/3.75`（直接用 vw，无需 JS）——但兼容性/边界（超大屏字号爆炸）需注意，常用 `clamp()` 限制：

```css
html { font-size: clamp(12px, 2vw, 22px); }  /* 12px ~ 22px 之间随 vw 走 */
```

## 4. 移动端适配三件套

### 4.1 视口 meta（前提，必须加）

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

**不加的后果**：手机默认按 980px 虚拟视口渲染 → 页面缩小、字看不清。`width=device-width` 让视口=设备宽度，才谈得上适配。

### 4.2 流式布局

```css
/* 宽度用 % / flex，不用固定 px */
.container { width: 100%; }          /* 或 flex: 1 */
.box { max-width: 100%; }           /* 防止溢出 */
```

### 4.3 图片适配

```css
img { max-width: 100%; height: auto; }   /* 不撑破、按比例缩放 */
/* 或响应式图片：按屏幕加载不同分辨率 */
<img srcset="small.jpg 480w, large.jpg 1080w" sizes="100vw">
```

## 5. 为什么这么设计

- **为什么需要响应式**：设备碎片化——手机/平板/桌面/大屏。做 N 套页面成本高、难维护；一套响应式代码用「断点 + 弹性」自适应所有设备。
- **为什么 rem 优于 em**：em 相对父元素字号，嵌套时层层相乘混乱；rem 相对根字号，全局唯一参照，改一处全局缩放。
- **为什么 vw 有时要 clamp**：vw 直接跟随视口宽——超宽屏（如 4K）字号会大到离谱，`clamp(min, val, max)` 限幅避免。

## 6. 高频追问速答

| 问题 | 一句话答案 |
| ---- | ---- |
| 响应式三大手段？ | 媒体查询 + 弹性单位（rem/vw）+ 移动端适配（viewport/流式） |
| 移动优先怎么写？ | 默认手机样式，`@media (min-width: 768px)` 逐步增强 |
| rem 和 em 区别？ | rem 相对根字号；em 相对父元素字号（易叠加混乱） |
| vw 是什么？ | 1vw = 1% 视口宽，直接跟随屏幕 |
| viewport meta 干嘛？ | 让视口=设备宽度，否则手机按 980px 缩小渲染 |
| 图片怎么适配？ | `max-width: 100%` + srcset 按屏加载 |
| 超大屏字号爆炸？ | `clamp()` 限幅 |

## 7. 面试速记（30 秒版）

> **响应式三件套：媒体查询（`@media` 断点，推荐移动优先 min-width 往上写）+ 弹性单位（`rem` 相对根字号、`vw` 相对视口，`clamp()` 限幅）+ 移动端适配（`meta viewport` 必加，宽度用 %/flex 流式，图片 `max-width:100%` + srcset）。** 经典题：rem 适配 = JS 动态设根字号（`width/设计稿宽*100`）或 `1rem = 100vw/N`；超大屏用 clamp 防字号爆炸。
