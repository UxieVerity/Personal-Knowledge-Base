④ 层叠上下文：z-index 999 的儿子 vs 父亲

B 的 z-index(2) > A 的 z-index(1) → B 整块（含儿子）盖住 A。若把 B 改小（如 z:0）就会看见 B 的儿子 999 也盖不住 A —— 跨上下文看父亲。
