# 两栏 / 三栏布局全家桶

> **结论：两栏 = 侧边栏固定 + 主内容自适应，5 种实现（float+BFC / flex / grid / table / 绝对定位）；三栏 = 左右固定 + 中间自适应，2 种主流（float 圣杯/双飞翼、flex/grid）。** 面试首选：**两栏用 `flex: 0 0 200px + flex: 1`，三栏用 `grid-template-columns: 200px 1fr 200px`（最简洁）。** 历史题（float 双飞翼/圣杯）了解原理即可——现代方案 flex/grid 一行搞定。
>
> 可运行验证：[[CSS综合-demo.html]]（浏览器实测：居中 / Grid 自适应列数 / 两栏三栏 / 层叠陷阱 / transform-vs-left 动画 / 响应式断点）

## 1. 一句话速览（背诵版）

| 布局 | 现代首选 | 一句话 |
| ---- | ---- | ---- |
| **两栏**（侧边栏+主区） | `flex: 0 0 200px` + `flex: 1` | 侧边固定、主区吃剩余 |
| **三栏**（左+中+右） | `grid-template-columns: 200px 1fr 200px` | 一行声明三列 |
| 三栏-经典 | float 圣杯/双飞翼 | 历史题，理解原理 |

## 2. 两栏布局（5 种实现）

### 2.1 Flex（推荐，一行）

```css
.layout { display: flex; }
.sidebar { flex: 0 0 200px; }   /* 固定 200px，不伸缩 */
.main { flex: 1; }              /* 占剩余 */
```

### 2.2 Grid

```css
.layout { display: grid; grid-template-columns: 200px 1fr; }
```

### 2.3 float + BFC

```css
.sidebar { float: left; width: 200px; }
.main { overflow: hidden; }     /* BFC → 不与浮动重叠，占剩余 */
```

**原理**：见 [[BFC]]——main 建 BFC 后不与左浮动重叠，自动让开剩余空间。经典老方案。

### 2.4 table

```css
.layout { display: table; width: 100%; }
.sidebar { display: table-cell; width: 200px; }
.main { display: table-cell; }
```

**原理**：table-cell 天然等高 + 平分宽度，侧栏给固定宽、主区吃剩余。老方案（table 布局遗风）。

### 2.5 绝对定位

```css
.layout { position: relative; }
.sidebar { position: absolute; left: 0; top: 0; width: 200px; height: 100%; }
.main { margin-left: 200px; }
```

**缺点**：侧栏脱离文档流，主区要手动 margin 让位。

## 3. 三栏布局（左右固定 + 中间自适应）

### 3.1 Grid（推荐，最简洁）

```css
.layout { display: grid; grid-template-columns: 200px 1fr 200px; }
```

**一行解决**——现代浏览器首选，中间 1fr 自适应。

### 3.2 Flex

```css
.layout { display: flex; }
.left, .right { flex: 0 0 200px; }
.middle { flex: 1; }
```

### 3.3 经典 float 双飞翼（历史题，面试要懂）

```css
/* 中间列先写（内容优先），左右用负 margin 拉到位 */
.middle { float: left; width: 100%; }         /* 中间占满 */
.middle-inner { margin: 0 200px; }            /* 内容让出左右 */
.left { float: left; width: 200px; margin-left: -100%; }
.right { float: left; width: 200px; margin-left: -200px; }
```

**双飞翼 vs 圣杯**：
- **双飞翼**：中间内容用 `margin` 让位（结构多一层 inner）
- **圣杯**：父容器 padding 让位 + 左右 relative 定位（不用 inner）

**共同点**：中间列 HTML 先写（**内容优先加载/SEO**），负 margin + float 实现。理解即可，现代不用——但面试常问「双飞翼/圣杯区别」。

## 4. 为什么这么设计 / 选型

- **为什么现代用 flex/grid**：float 布局要 hack（清浮动、负 margin、BFC），脆弱难维护；flex/grid 语义直接、天然等高、自适应。
- **两栏 vs 三栏选型**：两栏侧边栏常用 `flex: 0 0 Npx`（不伸缩固定）；三栏整体骨架用 Grid 一行。**Flex 管「两段」，Grid 管「三段+整体」**。
- **float 布局的价值**：理解历史（老项目维护、面试题）。核心 = 浮动 + 清浮动 + 负 margin 的配合。

## 5. 高频追问速答

| 问题 | 一句话答案 |
| ---- | ---- |
| 两栏怎么做？ | flex: 0 0 200px + flex: 1（或 grid 两列） |
| 三栏怎么做？ | `grid-template-columns: 200px 1fr 200px`（最简） |
| 双飞翼 vs 圣杯？ | 都靠负 margin+float；双飞翼用内层 margin 让位，圣杯用父 padding+relative |
| 双飞翼为什么中间先写？ | 内容优先加载（SEO）+ 负 margin 布局需要 |
| 为什么不用 float 了？ | 要 hack（清浮动/负 margin/BFC），flex/grid 语义直接 |
| 两栏等高？ | flex/grid 天然等高；float 要 hack |
| 侧边栏固定+主自适应？ | flex: 0 0 200px + flex: 1 |

## 6. 面试速记（30 秒版）

> **两栏 = 侧边固定 + 主区自适应**：`flex: 0 0 200px + flex: 1`（或 `float+BFC`、table、absolute）。**三栏 = 左右固定 + 中间自适应**：**`grid-template-columns: 200px 1fr 200px` 一行最简**；flex 版左右 `0 0 200px` + 中间 `flex:1`。**历史题双飞翼/圣杯**：中间先写（内容优先 SEO）+ 负 margin + float 拉到左右；双飞翼内层 margin 让位、圣杯父 padding 让位。**选型**：现代无脑 flex/grid，float 是理解历史的 hack。
